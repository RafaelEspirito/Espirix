# Espirix v0.3 — Authentication & Multi-Tenant Foundation

**Espirito Labs** · Java 21 / Spring Boot / React / TypeScript / PostgreSQL

O Espirix v0.3 é uma evolução de desenvolvimento que adiciona login, acesso por empresa, ambientes Demo e Trabalho, administração de usuários e limpeza de registros financeiros por workspace, com permissão e confirmação administrativa.

**Comece por [`GUIA-V03.md`](GUIA-V03.md)** para instalar sobre o projeto anterior, configurar credenciais, validar o isolamento e entender os limites da versão.

> Pré-produção. **Não use relatórios confidenciais nem exponha dados reais na internet** antes de autorização e validação de segurança, migrações, backups e revisão do código.
